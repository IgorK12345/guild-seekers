# Основные сценарии

1. Зарегистрироваться: герой 60 HP, учебный меч, задания, прогресс локаций.
2. Начать автоматический бой: ответные удары, постоянное HP, результат сохраняется
   независимо от открытого браузера. При 0 HP новый бой недоступен до восстановления.
3. Получить гарантированную вещь, редкое лечебное зелье или постоянный эликсир.
4. Надеть предмет; объединить три копии одной звёздности, максимум пять звёзд.
5. Вылечиться вне боя. В активном бою сервер отклоняет лечение и смену вещей.
6. Победить мини-босса с подходящим комплектом и здоровьем, открыть следующий этап.
7. Атаковать общего босса и получить ответный удар; проверить общее здоровье с другого аккаунта.
8. Повторно отправить тот же UUID боя: результат тот же, повторной добычи нет.
9. Перезапустить сервер и войти снова: HP, предметы, зелья и этапы сохранены.

Автоматические проверки описаны в tests/test_game.py. API: /docs.
