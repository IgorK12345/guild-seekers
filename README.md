# Гильдия искателей

Локальная браузерная RPG: Python + FastAPI, PostgreSQL, SQLAlchemy, HTML/CSS/JavaScript.

## Запуск

Дважды нажмите `Start.cmd`, затем откройте http://127.0.0.1:8000.
Остановка — `Stop.cmd`. Состояние игры сохраняется. Этот локальный адрес доступен только на вашем ПК.
Для демонстрации: логин `demo`, пароль `GuildDemo2026`. Можно создать свой аккаунт.
Этот аккаунт не создаётся автоматически на другой установке.

## Правила версии 2

- Нажмите «В бой». Герой и монстр автоматически обмениваются ударами до победы
  или поражения. Экран показывает анимацию, здоровье и урон каждого удара.
- Отступление и лечение в бою запрещены. Закрытие страницы не отменяет результат.
  При возвращении доступны результат и оставшаяся часть анимации.
- Здоровье сохраняется между боями. При поражении — 0 HP; опыт и предметы остаются.
- Каждая победа над обычным монстром даёт один предмет ★. Слизни/стражи/духи
  дают оружие; волки/големы/виверны — доспехи.
- Копии одинакового предмета одной звёздности складываются. Три копии → одна
  следующей звёздности, максимум ★★★★★. Надетый предмет заменяется улучшенным.
- В инвентаре можно надеть один меч и один доспех. Уровень не увеличивает их силу.
- Лечебное зелье выпадает с вероятностью 15%, восстанавливает 30% максимального
  здоровья и расходуется только вне боя. Начальных лечебных зелий нет.
- Эликсир жизненной силы автоматически применяется при выпадении: +10 максимального
  HP и +10 текущего HP. С каждой локации можно получить не более пяти.
- Первые четыре эликсира приходят с промежутками 3–5 побед (защита от невезения).
  Пятый — ещё через 6–10 побед. К 18 победам обычно набирается около четырёх.
- Мини-босс открывает следующую локацию. Уровень не блокирует вход. Мини-босса
  можно победить один раз; его награда — опыт и открытый путь.
- Три мировых босса сменяют друг друга: дракон (24 атаки), исполин (32), владыка
  пепла (40). У всех 5000 HP. За заход — один удар героя и один ответ выжившего
  босса. Новый босс появляется через минуту после смерти при следующем запросе.
- Задания дают дополнительный опыт. Предметы собираются в боях с обычными монстрами.

## Уровни и восстановление

База героя: 60 HP, 4 атаки, 0 защиты; учебный меч даёт +2 атаки.
Следующий уровень требует `300 × текущий уровень` опыта. Монстры этапов 1/2/3
дают 30/60/90 XP: около десяти побед на соответствующем уровне без бонусных наград.
На старой локации для более высокого уровня понадобится больше побед.

Регенерация вне боя: `максимальное HP × 0.001 × (1 + 0.1 × (уровень − 1))` в секунду.
На первом уровне это 1% за 10 секунд. Каждый следующий уровень даёт +10% базовой
скорости. Учитывается время при закрытой игре; полное HP не превышается.
Время самой анимации боя исключено. Запрет повторного боя действует только пока
текущий бой ещё идёт; отдельного двухсекундного ограничения больше нет.

## Проверка за несколько минут

1. Победите слизня, наденьте полученный меч: он сильнее учебного.
2. Победите волка и наденьте доспех.
3. Соберите по три копии вещей и объедините их в инвентаре.
4. Проследите, что HP не восстановилось сразу. Используйте выпавшее лечебное
   зелье или подождите — здоровье обновляется на экране каждые пять секунд.
5. Соберите комплект ★★★ и четыре эликсира, вылечитесь и победите мини-босса.
6. Попробуйте мирового босса: он тоже наносит урон. В другом браузере видно его
   общее здоровье. Вкладки одного профиля используют один аккаунт.
7. Перезагрузите страницу: уровень, HP, предметы, зелья и открытые локации сохранятся.

## Баланс мини-боссов

| Этап | HP босса | Атака босса | Герой с комплектом ★★★ | HP с нужными эликсирами | Остаток HP при победе |
|---|---:|---:|---|---:|---:|
| Лес | 110 | 33 | 22 атаки / 9 защиты | 100 (4 эликсира) | 4 |
| Руины | 186 | 41 | 31 атаки / 14 защиты | 140 (8 эликсиров) | 5 |
| Горы | 270 | 55 | 45 атаки / 20 защиты | 180 (12 эликсиров) | 5 |

Расчёт сделан для полного здоровья. Урон фиксированный: атака минус защита,
минимум 1. Герой ходит первым, убитый противник не отвечает. С одним эликсиром
меньше комплект ★★★ проигрывает; лучшая экипировка облегчает прохождение.
Второй этап: 4+4 и 5+3 эликсира равноценны. Это ориентиры баланса, а не запрет входа.
Сила звёзд: ×1 / ×1.5 / ×2.25 / ×3.375 / ×5.0625 с округлением до целого.

## Проверки и документация API

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты используют отдельную БД с суффиксом `_test` и пересоздают только её таблицы.
Проверяются бои, сохранение HP, регенерация, зелья, объединение, баланс мини-боссов,
мировые боссы, одновременные запросы, повторные награды и авторизация.
Swagger: http://127.0.0.1:8000/docs. Проверка связи с БД: http://127.0.0.1:8000/health.

## Установка и данные

На другом Windows-компьютере с Python 3.13 x64 выполните в PowerShell из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\Setup.ps1
```

Скрипт скачивает зависимости и официальный переносной PostgreSQL с EDB,
проверяет SHA-256, создаёт `.env`, применяет миграции и начальные данные.
Локальная оболочка `QuietShell.cs` обходит шумный AutoRun без изменения реестра Windows.
PostgreSQL слушает только `127.0.0.1:54329`; системная служба не создаётся.
Для Linux подготовлен Docker Compose; сборка и запуск проверены на VPS с Ubuntu 24.04.
Для него нужны `POSTGRES_PASSWORD`, `SECRET_KEY`, `PUBLIC_ORIGIN` в `.env`.
В интернете дополнительно нужны HTTPS, `SECURE_COOKIE=true` и резервное копирование.

- `.runtime/pgdata/` — игровые данные, не удаляйте ради перезапуска.
- `.runtime/backups/` — резервная копия перед обновлением и сбросом прогресса.
- `.runtime/server.log`, `.runtime/postgres.log` — журналы.
- `backend/app/balance.py` — формулы и общий симулятор боя.
- `backend/app/services.py` — игровые операции и транзакции.
- `backend/migrations/` — миграции. Переход на версию 2 один раз сбрасывает прогресс,
  сохраняя аккаунты; последующие запуски ничего не сбрасывают.
- `.env`, `.venv`, `.runtime` исключены из Git.
